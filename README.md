# Mio-Debug-Mode
This is a file that will let you enable debug mode in Mio: Memories in Orbit

To enable debug mode: 
1. Place VERY_SECRET_DO_NOT_OPEN in your MIO folder
For Steam go to your library -> right click Mio -> manage -> local files
For GOG go to your library -> right click Mio -> manage installation -> browse files

2. Open Mio and using a controller input this series on the d-pad:
↑  ↓  ↑  ↓  ←  →  ←  →  ↓  ←  ↑  →
(up, down, up, down, left, right, left, right, down, left, up, right)

4. click F11 for options
-while in a save you can click in on the left stick for some simple debugging and no-clip
-for a more detailed guide to debug mode see the [Mio discord](https://discord.gg/wpzEFrBQNS) in the [Debug mode guide thread](https://discord.com/channels/1391166350768078928/1523942886335451176)
